# نودها

برای پنل فقط یک VPS لازم است. نودها اختیاری اند: هر نود یک سرور دیگر است که ورودی های Xray انتخابی شما را با همان کاربران ارائه می دهد. پنل پیکربندی را به نودها می فرستد، ترافیک و وضعیت آن ها را جمع می کند و برای هر نود یک لینک به اشتراک کاربران اضافه می کند.

## افزودن نود

1. در پنل به **نودها ← افزودن نود** بروید. نام، IP یا دامنه سرور نود (کاربران به این آدرس وصل می شوند)، پورت ارتباط با پنل (پیش فرض `62050`) و ورودی هایی که نود باید ارائه دهد را وارد کنید.
2. پنل یک دستور نصب یک خطی نشان می دهد. آن را با کاربر root روی سرور نود اجرا کنید:

   ```bash
   bash <(curl -Ls https://raw.githubusercontent.com/veilonhq/veilon/main/installer/install.sh) node --token TOKEN
   ```

   دستور کامل را از پنل کپی کنید؛ `TOKEN` مخصوص همان نود است و کلید آن را دارد، پس آن را به کسی ندهید.
3. نصب کننده برنامه، Xray و سرویس `veilon-node` را راه اندازی می کند. چند ثانیه بعد نود آنلاین می شود.

پورت ارتباط با پنل باید از سرور اصلی در دسترس باشد. اگر ufw یا firewalld فعال باشد، نود خودش این پورت را باز می کند؛ در فایروال ارائه دهنده سرور هم آن را به همراه پورت ورودی ها باز کنید.

## نحوه کار

- پنل و نود با TLS دوطرفه (mTLS) با هم حرف می زنند؛ نود فقط پنلی را که آن را ثبت کرده قبول می کند.
- فقط ورودی های Xray (به جز TUN) روی نودها اجرا می شوند و روی سرور اصلی هم اجرا می مانند.
- ترافیک کاربران روی نودها مثل ترافیک سرور اصلی از سقف حجم آن ها کم می شود.
- صفحه نودها وضعیت (آنلاین، نیاز به بررسی، در دسترس نیست، در انتظار نصب، خاموش)، آخرین ارتباط، تاخیر، نسخه Xray، بار CPU، حافظه، ترافیک و همگام بودن پیکربندی را نشان می دهد.
- با خاموش کردن **نود فعال است** نود چیزی ارائه نمی دهد و لینک هایش از اشتراک ها حذف می شوند.
- **دستور نصب تازه** یک گواهی تازه صادر می کند؛ نود تا اجرای دستور تازه قطع می ماند.

## روی سرور نود

```bash
veilon node status
veilon node uninstall          # با --purge اطلاعات نود و فایل veilon هم حذف می شود
```

## محدودیت ها

- محدودیت IP و دستگاه هر کاربر فقط روی سرور اصلی اعمال می شود، نه روی نودها.
