# فایروال هر کاربر

دامنه ها و IP هایی را فقط برای یک کاربر ببندید. کاربر را باز کنید (**کاربران ← ویرایش**)، در بخش **فایروال** یک مورد بنویسید و **افزودن** را بزنید (یا چند مورد را یکجا بچسبانید، هر کدام در یک خط یا با ویرگول). فهرست می ماند تا وقتی که موردی را حذف کنید یا **حذف همه** را بزنید. کاربرانی که فایروال دارند در فهرست کاربران برچسب **فایروال: N مورد بسته** دارند. همین فهرست در ربات تلگرام (صفحه کاربر ← **🛡 فایروال**) و API هم هست.

Veilon از سایت هایی که کاربران باز می کنند هیچ سابقه ای نگه نمی دارد؛ فایروال فقط فهرست خود شما را اعمال می کند.

## قالب های پذیرفته

| آنچه می نویسید | ذخیره به شکل | چه چیزی بسته می شود |
| --- | --- | --- |
| `example.com`، `domain:example.com`، `*.example.com`، `https://example.com/path` | `example.com` | دامنه و همه زیر دامنه ها |
| `full:api.example.com` | `full:api.example.com` | فقط همین نام |
| `regexp:\.example\.(com\|net)$` | همان | نام هایی که با الگو جور هستند |
| `1.2.3.4`، `2001:db8::1` | همان | یک آدرس |
| `10.0.0.0/8`، `2001:db8::/32` | بازه، مرتب شده | یک بازه آدرس (CIDR) |

یک بخش تنها مثل `ir` کل دامنه سطح بالا را می بندد. پیشوند های دیگر (`geosite:`، `geoip:`، `keyword:`، `ext:` و ...) پذیرفته نمی شوند. موارد تکراری حذف می شوند.

## محدودیت ها

- حداکثر **۲۰۰ مورد** برای هر کاربر و هر مورد حداکثر **۲۵۳ نویسه**.
- بزرگ ترین بازه **/8 برای IPv4** و **/16 برای IPv6** است. برای قطع کامل کاربر، او را غیرفعال کنید.

## کجا اعمال می شود

- **ورودی های Xray و sing-box** (سرور اصلی و نودها): همه قالب ها. Xray ترافیک را به blackhole می فرستد و sing-box آن را رد می کند.
- **ورودی های AmneziaWG**: **فقط آدرس ها و بازه های IPv4** (رد کردن با nftables برای هر peer، جدول `inet veilon_userfw`). دامنه ها و موارد IPv6 آنجا اثری ندارند؛ اگر کاربر ورودی AmneziaWG داشته باشد، فرم این را می گوید.
- **MTProto** را شامل نمی شود.

## نکته ها

- **مورد IP ترافیکی را که با نام دامنه به سایت می رسد نمی بندد.** وقتی کلاینت با نام دامنه وصل می شود، Xray و sing-box نام را بررسی می کنند، نه آدرسی که به آن می رسد. برای بستن یک سایت دامنه اش را هم اضافه کنید (مورد IP تنها بیشتر اتصال مستقیم به آدرس و AmneziaWG را می گیرد).
- **ذخیره کردن هسته ها را کوتاه دوباره راه اندازی می کند.** هر تغییر تنظیمات را دوباره می سازد، پس ممکن است اتصال کاربران آن سرور یک لحظه قطع شود.
- **برای موارد AmneziaWG، نودها به برنامه نود همین نسخه (v0.3.13) نیاز دارند.** نود قدیمی تر کار می کند، اما IP های بسته شده روی ورودی های AmneziaWG آن نود اعمال نمی شوند؛ کارت نود و صفحه نود در ربات هشدار می دهند. موارد Xray و sing-box روی نودها با ارسال معمول تنظیمات کار می کنند.
- قوانین AmneziaWG در محیط آزمایشی تست شده اند، نه هنوز روی همه کرنل های واقعی. بعد از اولین تغییر، روی سرور `nft list table inet veilon_userfw` را بررسی کنید.

## API

`GET/PUT/POST/DELETE /users/{id}/firewall` و فیلد `firewall` کاربر. [api-v1](../api-v1.md#per-user-firewall) را ببینید.
