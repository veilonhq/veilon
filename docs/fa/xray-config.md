# پیکربندی Xray

در **بیشتر ← پیکربندی Xray** بخش هایی از پیکربندی هسته Xray را که ورودی نیستند ویرایش می کنید: خروجی ها، قوانین مسیریابی، متعادل کننده ها و DNS. ورودی ها و کاربران مثل قبل توسط خود پنل مدیریت می شوند.

## زبانه ها

| زبانه | کاربرد |
| --- | --- |
| **پایه** | خروجی پیش فرض، بستن دسترسی به شبکه خصوصی سرور (LAN و localhost)، ثبت درخواست های DNS در لاگ |
| **خروجی ها** | راه خروج ترافیک از سرور. اولین خروجی پیش فرض است؛ `direct` و `blocked` همیشه هستند. خروجی freedom، blackhole، VLESS، VMess، Trojan، Shadowsocks، SOCKS، HTTP یا WireGuard بسازید یا لینک اشتراک گذاری را بچسبانید |
| **مسیریابی** | قوانین از بالا به پایین بررسی می شوند (دامنه، IP، پورت، شبکه، پروتکل، ورودی، کاربر). هر قانون ترافیک را به یک خروجی یا متعادل کننده می فرستد. با فلش ها ترتیب را عوض کنید |
| **متعادل کننده ها** | پخش ترافیک بین چند خروجی: تصادفی، نوبتی، کمترین پینگ یا کمترین بار، با یک خروجی جایگزین |
| **DNS** | سرورهای DNS دلخواه برای هسته (در صورت نیاز فقط برای بعضی دامنه ها)، نوع درخواست، کش و هاست های ثابت. خاموش یعنی Xray از DNS سیستم استفاده می کند |
| **JSON پیشرفته** | همین تنظیمات به صورت JSON خام، برای هر چیزی که فرم ها ندارند |

## آزمایش و اعمال

- **آزمایش** پیکربندی را با خود Xray بررسی می کند و چیزی روی سرور تغییر نمی کند.
- **اعمال** پیکربندی را بررسی می کند و Xray را با آن ری استارت می کند. اگر Xray آن را رد کند، چیزی تغییر نمی کند. اگر Xray روشن نماند، پیکربندی قبلی خودکار برمی گردد.
- **برگرداندن تغییرات** همه ویرایش های ذخیره نشده را پاک می کند.

خروجی ای که در یک قانون یا متعادل کننده استفاده شده، تا وقتی آن ها را تغییر نداده اید حذف نمی شود.
